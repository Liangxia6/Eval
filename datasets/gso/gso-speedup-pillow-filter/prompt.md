# 颜色查找表插值与像素等价

你是可使用工具和修改工作区文件的 Agent。

输入 pixels 为行×列×RGB(0..255)整数，lut_size>=2，gamma 为三个正数。每通道查找表在 i/(lut_size-1) 建节点，值=255*(节点**gamma)。将输入像素归一化到0..1后线性插值相邻节点，四舍五入 floor(x+0.5) 并夹到0..255。输出 pixels、size=[宽,高]、avg_color（各通道均值，不舍入）。按完整像素检查，不能只优化均值。
