# 原始 Yelp 文本的小规模分类训练

你是可使用工具和修改工作区文件的 Agent。

输入train含text,label(0..4)，test仅评论文本。实现训练并预测的solve(data)，返回与test同序的整数标签数组。留出集准确率须>=0.25；各类等量，恒定类别仅0.20。允许任意模型，需实际从训练样本学习；可以保存参数与训练诊断到work。返回标签必须全部合法。文本长度不同，不得按文件顺序猜类。

交付 `output/solution.py`，提供 `solve(data)`，输入和输出必须可 JSON 序列化。公开样例见 `input/data.json`，评分侧另有同契约测试输入；必须实现通用逻辑。不得依赖只对样例有效的硬编码。执行每次调用不修改传入对象，异常按题意抛出。

保留 `input/` 原样，可在 `work/` 保存辅助代码和中间产物。最终回复说明完成内容及实际核验情况；不要把计划执行的步骤说成已经执行。方法不限，模拟参考步骤不是规定路线。

适配范围：
- 原私有测试文本重新划成新的作者区训练/留出（每类200/40），已不具备原私有测试身份，不可再用于原榜单。
- 使用1000/200小样本，阈值由原0.62改为本适配0.25。
- 允许非fastText实现，交付可运行训练预测程序；未验证原fastText二进制格式和150MB原约束。
