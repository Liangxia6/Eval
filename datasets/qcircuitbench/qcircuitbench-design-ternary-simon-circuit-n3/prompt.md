# 三元 Simon 测量后处理

你是可使用工具和修改工作区文件的 Agent。

输入 measurements 是三位0/1/2数组，每行y保证 y·s=0 (mod3)。恢复非零秘密向量的等价类{s,2s}。输出 candidates：满足全部方程的非零三元字符串，每个等价类只保留两者字典序较小者，最终升序。独立约束不足可有多个候选，不猜唯一。输入 measurements为空时输出全部13类。本题仅验证可运行的GF(3)后处理，不要求构建量子电路。

交付 `output/solution.py`，提供 `solve(data)`，输入和输出必须可 JSON 序列化。公开样例见 `input/data.json`，评分侧另有同契约测试输入；必须实现通用逻辑。不得依赖只对样例有效的硬编码。执行每次调用不修改传入对象，异常按题意抛出。

保留 `input/` 原样，可在 `work/` 保存辅助代码和中间产物。最终回复说明完成内容及实际核验情况；不要把计划执行的步骤说成已经执行。方法不限，模拟参考步骤不是规定路线。

适配范围：
- 使用重新编写的自包含小型科学计算输入和结果检查，不依赖上游环境。
- 保留数值方法关键边界；样例通过仅验证本适配契约。
- 大幅缩减为后处理切片；没有QASM、量子模拟或oracle调用证据，不得视为原量子算法题完成。
