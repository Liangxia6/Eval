# DSHEval 工作台设计原型

当前 `index.html` 使用传统工作台布局：左侧导航、顶部操作和运行摘要、中间执行队列、右侧所选题目详情。静态观测、计划、执行取证、标签评分和结果汇总通过页签切换。

视觉沿用项目报告的浅灰底、白色面板、细边框表格、灰底表头和绿色状态强调；不沿用报告的纵向章节布局。

全部内容为设计示例。按钮未接入真实 API，不会启动、停止评测或修改资源。此目录独立于评测核心。

`styles-20260912.html` 保留早期三种风格方案。

## Agent / Case 层级与动态评分（2026-09-14）

被测 Agent 为工作台顶层实体。当前评测范围下包含 Case；Case 下分别有执行事件、证据、产物和各标签评分。Agent 上方多维评分常驻，按当前评测范围内的 Case 结果自动计算，不混合不同评测批次。

原型包含 6 个一致的 Case 示例。点击“下一步”或“播放变化（演示）”逐步模拟证据新增、执行结束、每标签 Judge 返回及 null。每次更新都同步到 Case 列表、选中 Case 详情和 Agent 汇总。切换筛选不改变评分范围。

维度分数 = Σ有效分数×权重 / Σ有效权重；有效 0 分计入，null 与 Judge 错误排除，分别保留计数，无有效样本显示 —。权重仅作演示：代码题为 2，其余为 1。评分完成与执行完成分别统计。所有数据和事件均为本地演示，尚未接入后端事件或真实 LLM Judge。

验证：浏览器确认 Case 1 产物交付返回 4 后，Agent 产物交付从 2.33 更新为 2.75，数据处理从 — 更新为 3.00；独立脚本验证部分返回、加权汇总、筛选独立性、null、错误和有效零分。
